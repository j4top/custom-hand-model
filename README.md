#  Custom Hand Model

**Custom Hand Model** is a client-side Hypixel SkyBlock mod that gives you full control over your first-person hands, held items, and combat animations.

Inspired by the custom animation system from DulkirMod, Custom Hand Model focuses entirely on making your first-person gameplay look exactly the way you want it to.

## ✦ Features ✦ 
### Custom Item Positions

Move your held items exactly where you want them.

Customize:

- Position
- Rotation
- Scale

Create the perfect setup for your weapons, tools, and other held items without being limited to Minecraft's default first-person positioning.

### Custom Hand Models

Customize how your first-person hands look and feel while playing.

### Combat Animations

Fine-tune your first-person combat animations to create a setup that feels smooth and comfortable for your playstyle.

## ⚙ Configuration

Open the Custom Hand Model configuration menu using the default **H** key.

The keybind can be changed at any time in:


```
Options → Controls → Key Binds → Miscellaneous → Open Custom Hand Model Menu
```


Made for Hypixel SkyBlock

Custom Hand Model is designed specifically with Hypixel SkyBlock in mind, where custom first-person item positioning and combat animations can make a huge difference in how your gameplay looks and feels.
